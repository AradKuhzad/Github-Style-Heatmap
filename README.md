# GitHub Style Activity Heatmap

A simple GitHub-style activity heatmap built with vanilla JavaScript.

## Features

- Generate activity data for up to 365 days
- Random activity scores from 0 to 10
- Inactivity detection (7 consecutive zero-score days)
- Color-coded activity levels
- GitHub-style grid layout
- Uses:
  - for
  - while
  - if / switch
  - break
  - continue

## Technologies

- HTML
- CSS
- JavaScript
